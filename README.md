# Age Calculator

A simple web application that calculates age in *years, **months, and **days* based on the user's birthdate.

## Live Demo

Try it here:  
[Visit my website](https://lahcen-ouhassou.github.io/Age_Calculator/)

## Features

- Calculates accurate age in years, months, and days
- Clean and user-friendly interface
- Works instantly without reloading the page

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Enter your birth date.
2. Click on the "Calculate" button.
3. Your age will be displayed in years, months, and days.
